ANUVEDA ACADEMY — FREE PWA STARTER
==================================

WHAT THIS VERSION DOES
- Responsive website for mobile and desktop.
- Class 1–12 selection with subject lists.
- Links to official NCERT textbook portal and ePathshala.
- Installable PWA on supported Android browsers.
- Caches the app shell for repeat/offline opening.
- Does NOT host or redistribute NCERT PDF files.

IMPORTANT NCERT COPYRIGHT NOTE
Do not upload NCERT textbooks to your own hosting or bundle them into this app unless you have written permission or a licence that allows it. Link students to the official NCERT sources instead:
https://ncert.nic.in/textbook.php
https://epathshala.nic.in/

FREE PUBLISHING USING GITHUB PAGES
1. Extract this ZIP on your Windows 11 computer.
2. Open https://github.com/ and create a free account (if needed).
3. Click the + button > New repository.
4. Name it: anuveda-academy
5. Set repository visibility to Public. Create repository.
6. In the repository, choose Add file > Upload files.
7. Upload the CONTENTS of this folder (index.html, styles.css, app.js,
   manifest.webmanifest, service-worker.js, icons folder, images folder and this README).
   Do not upload the outer ZIP.
8. Click Commit changes.
9. Open repository Settings > Pages.
10. Under Build and deployment, choose Deploy from a branch.
11. Select branch main and folder /(root), then Save.
12. Wait a few minutes. GitHub will show your public website URL:
    https://YOUR-GITHUB-USERNAME.github.io/anuveda-academy/
13. Open that HTTPS link on your Android phone in Chrome.
14. Tap the three-dot menu > Install app or Add to Home screen.
    The exact wording can vary by Android/Chrome version.

TEST BEFORE SHARING
- Check the page on desktop and Android.
- Tap Class 1, Class 6, Class 10 and Class 12.
- Check that NCERT and ePathshala links open.
- Test the install option after deployment on HTTPS.
- Test once online, then reopen to check cached app shell.

HOW TO UPDATE
Edit the files on your computer, then upload changed files to the same
GitHub repository and commit the changes. GitHub Pages republishes them.

CURRENT LIMITATIONS / NEXT DEVELOPMENT PHASE
- The subject lists are a starter guide, not a definitive current NCERT catalogue.
- The app does not yet show a searchable, edition-verified NCERT book catalogue.
- No user accounts, quiz engine, bookmarks sync or admin panel yet.
- Do not promise offline textbook PDFs; the first version caches only its app shell.
- Add your own notes only after checking that you own or may distribute them.

FREE TOOLS
- Code editor: Visual Studio Code (optional; any text editor works).
- Hosting: GitHub Pages.
- PWA: included in this project.
- No paid database or server is required for this first version.
